# ~\.emacs.d for Windows

- Config folder (Windows): $HOME\AppData\Roaming\.emacs.d
- Config file: ~\.emacs.d\init.el

# Features

1. Evil mode (Fully included)
2. Eat terminal (Fully included)
3. Shell replaced to `pwsh.exe` (Must be available in $PATH) in both shell command and eat terminal

## Custom keymaps

- `C-c t` spawns a new eat terminal
- `C-c C-s` shell command

### Evil

- `C-j`, `C-k` movie lines down and up
- `H` move to first character in line
- `gl` goto last location
